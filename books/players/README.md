# Player books

## Origins

- `ph-` books were made by Pawel Hase and downloaded from
  [ChessPraga](http://www.chesspraga.cz/spikebook.htm).
- `rj-` books were downloaded from
  [Robinson Special Jeux](https://robinson-special-jeux.franceserv.com/famous-personnality.html).
- `bn-` books are from Brendan J. Norman.
- Books without these prefixes were made by Pawel Koziol.

## Original book notes

The following names and descriptions are retained from the original notes;
some names differ from the files currently shipped in this directory.

| Original name | Description |
| --- | --- |
| `kasparov.bin` | Kasparov's games from PgnMentor as the first layer, with games from 1980 to 2006 as the second layer. |
| `nimzowitsch.bin` | Nimzowitsch's games from PgnMentor as the first layer, with pre-1930 games from Norm Pollock's collection as the second layer. |
| `petrosian.bin` | Petrosian's games from PgnMentor as the first layer, with games from 1931 to 1980 from Norm Pollock's collection as the second layer. |
| `ph-andersson2.bin` | An interesting book for a solid player. |
| `ph-short2.bin` | 1.e4 as White; Nimzo-Indian and mostly French as Black. |

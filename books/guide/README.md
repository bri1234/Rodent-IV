# Guide books

These books guide the game stylistically. Use them with a main book such as
`rodent.bin`.

| Book | Style and origin |
| --- | --- |
| `active.bin` | Seeks dynamic positions; based on Kasparov's games without QGD, with Benoni added for variety. |
| `cat.bin` | Catalan, classical Queen's Indian and g3 KID as White; Grunfeld, accelerated Dragon, Modern and Alekhine as Black. Needs a main book in reserve. |
| `cs.bin` | d4, occasionally c4 as White; Caro-Kann and Slav as Black, occasionally Nimzo-Indian. Requires a strong main book because it chooses sharp lines. |
| `closed.bin` | French and King's Indian as Black; d4 and e4 as White. |
| `empty.bin` | Empty book; can be used as a main book for weak personalities with limited opening knowledge. |
| `flank.bin` | Flank openings and fianchettoing bishops; based on Tomasz Markowski's games with some lines added by hand. |
| `grandpa.bin` | Small book; Caro and Tarrasch as main Black options, Ruy and Nimzo as backup. Prefers d4 to e4 as White. |
| `low.bin` | Minimal book that starts with moves that do not reach the fourth or fifth rank. |
| `solid.bin` | Karpov and Uhlmann. |
| `tricky.bin` | Morozevich's games with extensive manual additions; wide and tricky. |

# Opening books

The default main book is `rodent.bin`, accompanied by the stylistic guide book
`guide.bin`.

- [Guide books](guide/README.md)
- [Historical books](hist/README.md)
- [Main book alternatives](main/README.md)
- [Player books](players/README.md)

## Chess960 book origin

`guide_960.bin` was taken from `CHESS_960Book.bin.zip` in the
[Stockfish XR7 release](https://github.com/MichaelB7/Stockfish/releases/tag/XR7).
It is intended to add variety to play rather than increase the engine's strength.
